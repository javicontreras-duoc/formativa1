# Sistema de Gestión de Gatitos 🐾

Aplicación web desarrollada con HTML, CSS y JavaScript para el registro y visualización de gatos. El proyecto utiliza la API de `localStorage` para almacenar la información de forma persistente en el navegador sin necesidad de una base de datos externa.

## Características

* **Inicio (`index.html`):** Menú principal interactivo para navegar entre secciones.
* **Registro (`formulario-gato.html`):** Formulario con validaciones en tiempo real usando JavaScript para ingresar el nombre, color de pelaje y edad del gatito.
* **Listado (`lista-gatos.html`):** Tabla dinámica que lee los datos guardados en `localStorage` y muestra los registros creados.
* **Diseño Responsivo:** Hojas de estilo CSS personalizadas con temática felina e interfaz accesible.

## Tecnologías Utilizadas

* **HTML5:** Estructura semántica de las páginas web.
* **CSS3:** Estilos personalizados, variables CSS y diseño adaptable.
* **JavaScript (ES6):** Manipulación del DOM, validación de formularios y persistencia de datos mediante `localStorage` y `JSON`.
